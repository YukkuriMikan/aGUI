# aGUI Reference

`aGUI` (`ANest.UI`) の Runtime API リファレンスです。  
対象コードは `Assets/package/Runtime` 配下の `public` 型です。

## カテゴリ

- [Container / Cursor](containers.md)
- [Selectable](selectables.md)
- [Layout Group](layout-groups.md)
- [Component](components.md)
- [Animation](animations.md)
- [Manager / Utility](managers-utilities.md)

## 使い方

1. まずカテゴリページから型を探す
2. `主な API` で利用するメソッド/プロパティを確認する
3. `Source` のリンクから実装へジャンプする
